# Randomizer (Smart Cascade Wheel)

Офлайн Android-приложение: каскадная рулетка решений со шпаргалками (текст + фото).
Пакет `dev.ronova.randomizer` · Kotlin · Jetpack Compose (Material 3) · Room · minSdk 26.

## Что внутри
- **Каскад** этапов с условными правилами: *подмена списка* и *исключение элемента* (срабатывают от элемента, выпавшего на предыдущем этапе).
- **Режимы**: каскад / одиночный этап. Профили-пресеты: активные этапы, режим и этап по умолчанию, фильтр по тегам.
- **Вращение**: анимация колеса, вибро и звук (переключатели на главном экране), окно результата «Перекрутить / Далее».
- **Итог**: карточка результатов, замочки (фиксация пункта), единая шпаргалка (фото, текст, галерея с просмотром), «Сохранить в историю».
- **Редактор**: этапы (перетаскивание), списки, элементы (поиск, фильтры, чекбоксы), правила, профили.
- **История**: лента с датой/профилем, фотоотчёт.
- **Перенос**: один файл `.scw` (zip: `data.json` + `photos/`), экспорт «Полный» / «Только списки», отправка через Share Sheet; импорт «Слияние» или «Полная замена».
- Фото ужимаются до 1080 px (WebP на Android 11+, иначе JPEG). Адаптивный UI: на планшете двухколоночные экраны.
